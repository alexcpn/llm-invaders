Why this game

Robots, autonomous cars and trading systems need decisions that land before the world moves on: an arm catching a falling object, a car braking for a child, a trade placed before the other side reacts. A brilliant answer that arrives late is a wrong answer. Language models are judged on how deeply they think; this experiment asks whether speed of thought matters as much as depth of thought. Space Invaders makes the trade-off measurable: every decision has a deadline, and the speed dial turns thinking time into game time.

Both matter, and speed comes first. Latency sets a ceiling no judgement gets past: a perfect coded player wins almost nothing once its decisions are more than 0.13 game seconds apart. Inside that ceiling, judgement decides: Gemma 4 E2B thought more than twice as fast as Jev and won nothing, because it only ever fired; Microsoft-Decision-1, about as fast as Jev, won nothing because it mostly waited. Only Jev, fast and with the best judgement, won games. Speed is necessary but not sufficient, which is why robots split the work: a slow model reasons about goals while a small fast policy acts every few milliseconds.

How it was measured

The game is a small, deterministic Space Invaders: 18 aliens march sideways, drop a row at each edge, speed up as they thin out and drop bombs. The cannon moves one column per action and has one shot in flight. Clearing the wave wins; the aliens landing or losing three lives loses.

Each decision, the game freezes, the model gets the board as a short text description and picks one action: left, right, fire or wait. The game then runs on for the model's measured latency times the game speed before the action lands, so a slow model acts on a stale view, as it would in real play, while results stay reproducible. This follows the latency-controlled protocol used by OmniGameArena.

Jev and Microsoft-Decision-1 are System-1 decision models: they return a probability for each fixed option in one pass instead of writing text, called through OpenRouter's /api/alpha/decisions endpoint; the most likely action is played. Gemma 4 E2B runs on the laptop's RTX 3060 through Ollama with thinking switched off and a strict JSON answer. Every paid call was logged against a hard $1.90 stop.
